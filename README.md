# Moustafa Ahmed

I'm a backend engineer working mostly in **Laravel, PHP, and MySQL**. I like the
parts that are easy to get wrong — stock that shouldn't be double-booked,
callbacks that arrive twice, jobs that half-succeed — and the tests that prove
they don't.

## Things I've built

- **[Warehouse Inventory Reservation Engine](https://github.com/Moustafa-Ahmed/warehouse-inventory-engine)** — an inventory core for a multi-warehouse ERP that keeps stock correct under concurrent reservations, partial fulfillment, and duplicate webhooks. `Laravel · MySQL · Pest`
- **[Career 180 LMS](https://github.com/Moustafa-Ahmed/lms)** — courses, lessons, enrollment, and progress tracking, with an admin panel. `Laravel · Livewire · Filament`
- **[Business Flow Explorer](https://github.com/Moustafa-Ahmed/flow)** — turns a codebase's business logic into a role-based mind map and clickable flowcharts. `React · TypeScript`
- **[Agent Code Plan](https://github.com/Moustafa-Ahmed/Agent-Code-Plan)** — a small planning board (table + Kanban) that agents keep up to date from one JSON file. `HTML · JSON`

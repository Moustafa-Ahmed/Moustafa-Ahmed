Backend engineer. Most of my work is Laravel, PHP, and MySQL.

I tend to end up on the parts that are hard to get right: keeping stock counts
accurate when reservations overlap, handling shipping callbacks that arrive
twice, retrying jobs that only got halfway. I write tests for those cases.

- **[Career 180 LMS](https://github.com/Moustafa-Ahmed/lms):** a small learning platform with courses, lessons, enrollments, and progress tracking. Includes an admin panel. `Laravel` `Livewire` `Filament`
